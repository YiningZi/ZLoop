# 当前限制与改进计划

这些条目按当前 2.2.1 源码核对，供后续维护跟踪；不是已经实现的新功能。

## 影响范围

- “仅影响相连项”按拓扑路径限定影响，不能自动识别单根手指。过大的半径仍可能经掌部到达其他手指。
- 自动半径使用环线转角和局部网格间距的启发式，尚未完整分析曲面曲率。
- 自动半径的环线坐标使用世界空间，而邻层间距来自局部坐标；非均匀物体缩放下需要进一步统一度量并增加验证。

## 控件与缩放

- “保持形状”和“均匀偏移”会传递并保存属性，但当前缩放流程未使用这些值实现独立的几何处理。
- “缩放方向”改变变换方向设置；当前执行三轴等比例缩放且没有轴约束，因此不能视为只沿法线或单轴变形。
- 每次缩放只支持一条闭合环线。测量工具会统计选中的全部边，不会自动限定为有效单环线。
- 测量结果显示于报告/状态栏，尚未增加持久的面板测量结果。

## 后续修改顺序

1. 统一自动半径的坐标度量，覆盖物体缩放、单位设置和极端网格密度。
2. 删除无效控件或实现对应行为，并更新文档和验证。
3. 根据实际手掌模型改进局部衰减，增加手指根部和高曲率场景。
4. 增加多条环线处理与面板测量反馈。

提出或处理问题时使用仓库 Issues，写明 Blender 版本、插件版本、复现步骤、预期效果和实际效果。
