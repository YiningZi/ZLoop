# ZLoop 环线工具 2.2.0

## 安装与更新

在 Blender 的“编辑 → 偏好设置 → 插件”菜单中选择“从磁盘安装”，选择 ZIP，无需解压。更新前先禁用旧版，安装后重新启用。新版仍使用 zloop_addon 模块名，以覆盖原插件。此包使用传统插件格式。

在 3D 视图按 N，打开 ZLoop 标签页。选择网格物体，进入编辑模式并选择一条完整闭合环线。

## 仅影响相连项

位置：“比例衰减”分组顶部。默认开启，对自动衰减和手动半径均有效，也可在“调整上一步操作”中修改。

- 开启：使用 Blender 的相连比例编辑，沿网格连接计算影响距离。另一根手指即使空间上很近，也不会仅因靠近就受到影响；当前手指附近仍有平滑衰减。
- 关闭：使用普通空间距离衰减，附近其他部位可能一起变化。
- 手指通过掌部连接，半径过大仍可能沿掌部传到其他手指。调整指围建议同时开启“仅影响相连项”和“自动衰减”。需要严格隔离时，可先隐藏不希望调整的网格部分。

本功能不自动识别或分割手指。请选择需要调整的那一条环线，并保持局部半径。

## 2.2.0 更新

- 增加默认开启的“仅影响相连项”选项。
- 每次操作明确指定相连衰减，并关闭屏幕投影距离计算，避免被上次工具状态影响。
- 缩放结束或失败后恢复原有比例编辑设置。
- 修复旧版通过 Python 类名查找注册项无效的问题，改为通过 Blender RNA 标识符注销。
- 注销时清理插件自己的 Scene 属性值，兼容 Blender 4.4 和 5.1；重复注册保留当前参数。
- 打包仅包含源码与此说明，不包含 Python 字节码缓存。

## 验证范围

已在 Blender 4.4.3 和 5.1.1 的独立后台进程中运行网格变形回归测试：使用两根侧面靠近、底部通过面连接的管状网格，验证自动/手动半径下相邻手指保持不动、当前手指局部平滑变形和目标周长精度，并验证关闭选项会恢复空间距离影响。另测不相连网格、异常后的设置恢复、重复注册、模块替换与注销清理。

测试模型不是你的实际手掌模型，复杂拓扑仍需按实际形状选择合适半径。插件自身不能保证所有旧版本或 Blender 的模块加载问题都无需重启；本版验证的是注册资源与参数的清理。
