# 历史版本与归档范围

本仓库以目前可核验的 ZLoop 2.2.0 源码作为首次 Git 导入。2.0.0、2.1.0 的说明依据此前的修改记录整理，未把新源码伪装成旧版，也未补造历史提交或旧安装包。

| 版本 | 记录日期 | 主要变化 | 归档情况 |
| --- | --- | --- | --- |
| 2.0.0 | 2026-09-09 | 原始周长控制、中文 UI、面板显示修复、安装包整理 | 已保存文字记录；当前工作区没有可核验的独立旧版源码或 ZIP。 |
| 2.1.0 | 2026-09-09 | 生命周期清理、局部曲率启发式自动半径 | 已保存文字记录；当时多个迭代复用了同一元数据版本。 |
| 2.2.0 | 2026-09-16 | 仅影响相连项、设置恢复、修复 RNA 注销、网格回归测试 | 有可核验源码；本仓库提供构建与 Release。 |
| 2.2.1 | 2026-10-12 | GPL-3.0-or-later 许可证、安装包版权声明与许可证全文、仓库说明完善 | 独立源码版本与 Release；此前发布保持原样。 |

版本说明见 [CHANGELOG](../CHANGELOG.md)。Git 导入日期为 2026-10-12，历史记录日期与 Git 提交日期含义不同。

后续每个发布版本必须包含：独立版本号、对应 Git 标签、中文更新说明、经过验证的安装包及 SHA-256 校验文件。找到可验证的旧源码或旧包后，可补充历史归档并说明来源。
